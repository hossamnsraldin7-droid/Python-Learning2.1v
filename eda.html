01. What is EDA

Exploratory Data Analysis (EDA) is the process of examining a dataset before building a Machine Learning model. It helps us understand the structure, quality, patterns, relationships, and unusual values in the data.

EDA mainly answers questions such as:

  • How many rows and columns are in the dataset?
  • What does each column represent?
  • Are there missing or duplicated values?
  • Are there outliers or unusual distributions?
  • Which features are related to each other or to the target?
Important: EDA is not just creating charts. It is a reasoning process: inspect the data, ask questions, test assumptions, and document what you discover.

02. EDA Workflow

Follow this order when starting a new dataset:

Step 1 — Load the dataset: Import the required libraries and read the file.
Step 2 — Preview the data: Display the first and last rows.
Step 3 — Understand the structure: Check shape, column names, data types, and memory information.
Step 4 — Generate statistics: Inspect count, mean, standard deviation, minimum, maximum, and quartiles.
Step 5 — Check data quality: Find missing values, duplicates, and invalid values.
Step 6 — Clean the data: Handle missing values, duplicates, and incorrect data types when appropriate.
Step 7 — Explore individual features: Study distributions and category frequencies.
Step 8 — Explore relationships: Compare features and inspect correlation where suitable.
Step 9 — Summarize findings: Record useful observations and decide what preparation is needed before modeling.
The workflow is a guide, not a strict law. You may return to earlier steps when a chart or statistic reveals a data-quality problem.

04. Basic EDA

4.1 Preview the Dataset — head() and tail()

head() displays the first rows; tail() displays the last rows. They help us quickly inspect values and column layout.

df.head()       # First 5 rows
df.head(10)     # First 10 rows
df.tail()       # Last 5 rows

shape returns a tuple: (number_of_rows, number_of_columns).

print(df.shape)

# Example output:
# (150, 5)

4.3 Column Names — columns

Use columns to display all feature names.

print(df.columns)

4.4 Data Types and Non-Null Counts — info()

info() shows column names, non-null counts, data types, and memory usage.

df.info()

describe() generates statistical summaries for numeric columns by default.

df.describe()

unique() returns the distinct values; nunique() counts them.

print(df["category"].unique())

print(df["category"].value_counts())

05. Data Cleaning

5.1 Missing Values — isnull() and isna()

Missing values can affect statistics and Machine Learning models.

# Number of missing values in each column
print(df.isnull().sum())

# Percentage of missing values
missing_percent = df.isnull().mean() * 100
print(missing_percent.sort_values(ascending=False))

5.2 Handling Missing Values

Choose a method based on the feature meaning, missingness pattern, and analysis goal.

# Remove rows containing at least one missing value
df_drop_rows = df.dropna()

# Fill a numeric column with its median
df["age"] = df["age"].fillna(df["age"].median())

# Fill a categorical column with its most frequent value
df["city"] = df["city"].fillna(df["city"].mode()[0])
Median is often more robust than mean when numeric data contains extreme values. However, no single filling method is correct for every dataset.

5.3 Duplicate Rows — duplicated() and drop_duplicates()

# Count duplicated rows
print(df.duplicated().sum())

# Remove duplicated rows
df = df.drop_duplicates()

5.4 Data Types — astype()

Sometimes a column contains numbers stored as text. Convert it only after checking its values.

# Convert a column to integer
df["age"] = df["age"].astype("int64")

# Convert a column to datetime
df["date"] = pd.to_datetime(df["date"], errors="coerce")

5.5 Check and Handle Outliers

An outlier is a value that is unusually far from most observations. It may be an error, a rare valid case, or an important observation.

IQR method: IQR = Q3 - Q1. A common rule flags values below Q1 - 1.5 × IQR or above Q3 + 1.5 × IQR.

Q1 = df["salary"].quantile(0.25)
Q3 = df["salary"].quantile(0.75)
IQR = Q3 - Q1

lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

outliers = df[
    (df["salary"] < lower_bound) |
    (df["salary"] > upper_bound)
]

print(outliers)
Do not delete outliers automatically. First investigate whether they are data-entry errors or genuine observations. Removing valid values can damage the analysis.

06. Data Visualization

Charts help reveal distributions, patterns, class imbalance, and relationships.

6.1 Histogram — Distribution of a Numeric Feature

A histogram groups numeric values into bins and shows how frequently values occur.

plt.figure(figsize=(8, 5))
sns.histplot(data=df, x="age", bins=20, kde=True)

plt.title("Age Distribution")
plt.xlabel("Age")
plt.ylabel("Frequency")
plt.show()

6.2 Boxplot — Spread and Potential Outliers

A boxplot displays the median, quartiles, spread, and potential outliers.

plt.figure(figsize=(8, 5))
sns.boxplot(data=df, x="salary")

plt.title("Salary Boxplot")
plt.show()

6.3 Countplot — Categorical Frequencies

Use a countplot to compare the number of observations in each category.

plt.figure(figsize=(8, 5))
sns.countplot(data=df, x="category")

plt.title("Category Counts")
plt.xticks(rotation=45)
plt.show()

6.4 Scatterplot — Relationship Between Two Numeric Features

A scatterplot helps identify trends, clusters, and unusual points.

plt.figure(figsize=(8, 5))
sns.scatterplot(data=df, x="age", y="salary")

plt.title("Age vs Salary")
plt.show()

6.5 Correlation Heatmap

Correlation measures the strength and direction of a linear relationship between numeric variables. Values range from -1 to +1. 

numeric_df = df.select_dtypes(include="number")
corr = numeric_df.corr()

plt.figure(figsize=(10, 7))
sns.heatmap(corr, annot=True, cmap="coolwarm", fmt=".2f")
plt.title("Correlation Heatmap")
plt.show()
Correlation does not prove causation. A strong correlation does not mean that one feature causes the other. Also, Pearson correlation mainly measures linear relationships.

07. Advanced EDA

7.1 Grouping Data — groupby()

groupby() splits data into groups, applies an operation, and combines the results.

# Average salary for each department
print(df.groupby("department")["salary"].mean())

# Multiple statistics
summary = df.groupby("department")["salary"].agg(
    ["count", "mean", "median", "min", "max"]
)
print(summary)

7.2 Compare Features with hue

The hue parameter adds a third categorical variable using different colors.

plt.figure(figsize=(8, 5))
sns.scatterplot(
    data=df,
    x="age",
    y="salary",
    hue="department"
)

plt.title("Age and Salary by Department")
plt.show()

7.3 Pairplot — Relationships Across Several Features

pairplot() creates pairwise plots for selected numeric features. Use it with a small number of columns because it can become slow and crowded on large datasets.

selected = df[["age", "salary", "experience", "department"]]

sns.pairplot(
    selected,
    hue="department",
    diag_kind="hist"
)
plt.show()

7.4 Skewness — Distribution Asymmetry

Skewness describes whether a distribution is asymmetric.

# Calculate skewness for numeric columns
print(df.select_dtypes(include="number").skew())
SkewnessGeneral interpretation

7.5 Feature Relationships with a Target

Before modeling, inspect how features behave across target classes or target values. For a classification target, compare feature distributions by class. 

# Example: numeric feature distribution for each target class
sns.boxplot(data=df, x="target", y="age")
plt.title("Age by Target Class")
plt.show()

# Class distribution
print(df["target"].value_counts(normalize=True))

7.6 Create a New Feature — Feature Engineering

Feature engineering means creating useful features from existing data.

# Example: create an age group
df["age_group"] = pd.cut(
    df["age"],
    bins=[0, 18, 35, 60, np.inf],
    labels=["Child", "Young Adult", "Adult", "Senior"]
)

print(df[["age", "age_group"]].head())
Machine Learning note: For predictive modeling, learn preprocessing rules (such as imputation and scaling) from the training set only, then apply them to validation and test sets. This prevents data leakage.
